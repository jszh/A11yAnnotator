# WCAG Understanding docs (in-scope SCs)

The W3C **Understanding** documents for our 22 in-scope Success Criteria (the SCs in
[`categories.json`](../categories.json)), pulled verbatim from the W3C source. Understanding docs carry the
*Intent* and the testing reasoning behind each SC — the richest source for "what interaction does verifying
this SC actually require," which is why they back the interactive-tool analysis.

## Provenance
- **Source repo:** [`w3c/wcag`](https://github.com/w3c/wcag), `main` branch, `understanding/{20,21,22}/<slug>.html`
  (each SC's doc lives under the WCAG version that introduced it).
- **Fetched:** 2026-06-17 (shallow clone, copied verbatim — no edits).
- **License:** W3C Document License.
