# Capability-gap analysis — 1.1.1, 4.1.2, 2.4.4 (name + link)

Scope: 21 aspects across **1.1.1 Non-text Content** (7), **4.1.2 Name, Role, Value** (8),
**2.4.4 Link Purpose (In Context)** (6). Judged adversarially against the CURRENT harness
capability (rubrics + precomputeSignals + CDP tools + act-page-collect). A rubric existing does
NOT make an aspect COVERED — the question is whether the *evidence handed to the rubric* is
sufficient for the facet. "PARTIAL" here = the capability exists but is not wired/required for
this facet (a routing/wiring gap, recoverable by enabling/requiring an existing producer or
collecting a present-in-DOM fact); "GAP" = a missing evidence/signal/runner/tool/judgment.

Reference instruments: WCAG 2.2 Understanding/Techniques (F3, F13, F20, F30, F39, F65, F67, F89,
H2, H30, H36, H37, H67, ARIA6, ARIA10, ARIA14, ARIA15, ARIA16, G92, G94, G53, G91, G130, G183,
C9), Trusted Tester v5.1.3 (7.A/7.B/7.C/7.D, 10.x, 13.x), EN 301 549 §9.1.1.1 / §9.4.1.2 / §9.2.4.4.

## Capability tags (clustered)

Distinct capabilityTags and the aspects each covers. Tags are grouped by the underlying missing
capability so the same fix retires multiple aspects.

### A. Dynamic / post-activation observation of name-role-value (the biggest cluster — resting-crop blindness)
The 4.1.2 rubric judges only the RESTING crop+axName; multiple aspects need the control DRIVEN
and its name/value/state RE-READ after activation. Tools (`observe_state_after_activation`,
`set_state_and_capture`, `probe_screen_reader_after_action`, `query_ax_node`) exist but none
re-reads the recomputed accessible NAME or tests value settability, and none is required by the rubric.
- `dynamic-name-after-activation` — 4.1.2 stale-text-alternative-on-dynamic-named-component (GAP)
- `live-state-correctness` — 4.1.2 stale-or-contradicting-state-value (PARTIAL: state surfaced at rest, not judged/driven)
- `value-settability-probe` — 4.1.2 value-not-settable-or-change-not-notified (GAP)
- `role-appropriateness-judgment` — 4.1.2 wrong-role-valid-but-inappropriate (PARTIAL: signal surfaced, unowned by any rubric)

### B. Destination resolution for link purpose (tool exists, LLM-discretionary + same-origin-only)
`resolve_destination` is catalog-routed to 2.4.4 but never required; raw hrefs are surfaced. The
gap is (a) requiring/auto-running it, (b) cross-origin coverage, and (c) a name-vs-destination
SUBJECT comparison mode the rubric lacks.
- `same-name-destination-resolve` — 2.4.4 duplicate-name-same-context-different-purpose (PARTIAL)
- `name-vs-destination-subject` — 2.4.4 descriptive-name-contradicts-on-page-destination (GAP)
- `icon-link-purpose` — 2.4.4 icon-link-name-present-but-wrong-or-meaningless (PARTIAL)
- `functional-alt-context` — 1.1.1 context-and-function-dependent-equivalence (PARTIAL; a LINKED image's alt also needs the destination, not routed to the 1.1.1 skill)

### C. Image text extraction (OCR exists, not required; sidecar-gated; no lookalike detector)
- `ocr-vs-alt-compare` — 1.1.1 image-of-text-alt-omits-the-text (PARTIAL: ocr_image_text routed but discretionary + sidecar-gated)
- `glyph-substitution-detect` — 1.1.1 text-lookalike-glyph-substitution (GAP: no detector for icon-font/homoglyph/pseudo-element text)
- `css-background-meaning-judgment` — 1.1.1 informative-css-background-image (PARTIAL: resting-crop only, no reveal-state, no bg OCR)

### D. Resolving associated TEXT/CONTENT the rubric claims to receive but doesn't
A boolean presence flag stands in for the actual associated text/content.
- `long-description-resolver` — 1.1.1 complex-image-long-description-incomplete (GAP: complexImageHint is a boolean; describedby/figcaption/details/adjacent-table TEXT never resolved)
- `iframe-content-summary` — 4.1.2 iframe-name-does-not-describe-content (GAP: no frame subject summary; title captured for captcha only; rubric refuses the check)

### E. Visible-text extraction + label-in-name comparison (deferred to a non-existent 2.5.3 owner)
- `visible-vs-programmatic-name` — 4.1.2 name-omits-visible-label-text (PARTIAL: rubric defers to 2.5.3; no producer extracts visible label text or compares to axName)

### F. Structural grouping the per-element collector does not assemble
- `multipart-field-grouping` — 4.1.2 multipart-field-subnames-ambiguous (GAP: sibling sub-fields never grouped into a compound control)
- `heading-list-scope-ancestry` — 2.4.4 preceding-heading-or-list-grouping-context-sufficiency (PARTIAL: enclosing block captured; section/heading-scope ancestry (H80) not modeled)

### G. Adequately COVERED (evidence sufficient — no fix needed)
- `tree-removal-redundancy-judgment` — 1.1.1 meaningful-image-suppressed-as-decorative
- `alt-string-quality-judgment` — 1.1.1 alt-not-an-alternative-filename-placeholder
- `name-identity-judgment` — 4.1.2 name-present-but-not-descriptive-of-purpose
- `enclosing-context-judgment` — 2.4.4 generic-link-text-no-rescuing-context AND context-outside-programmatic-link-context-f63 (one capability, two aspects)
