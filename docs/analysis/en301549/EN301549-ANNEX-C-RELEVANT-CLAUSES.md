# EN 301 549 V4.1.0 — Annex C relevant clauses (verbatim extract)

> **Internal ETSI standardization working material. EN 301 549 is © ETSI/CEN/CENELEC.** Source:
> `refs/en_301549v040100ev.pdf` *Draft EN 301 549 V4.1.0 (2025-11)*, Annex C (normative) *Determination
> of conformance*. Like `refs/`, this file is **not for publication** — it reproduces only the clauses of
> the standard relevant to this project's selected categories, for internal gap analysis. Analysis and
> grading live in [EN301549-ANNEX-C-ANALYSIS.md](./EN301549-ANNEX-C-ANALYSIS.md).

Scope: **clause C.9 (Web)**. Each of our 22 selected SCs is listed with its EN clause and the verbatim
Annex C test. **For individual web criteria every test is WCAG-2.2 pass-through** (identical shape); the
clauses adding EN-specific requirements are **C.9.6** (conformance requirements) and **C.9.7** (user
preferences). Non-web parallels (C.10 documents, C.11 software) are out of the harness's scope.

## Conformance-scope clauses (EN-specific — not per-criterion tests)

### C.9.6 — WCAG 2.2 conformance requirements

```
C.9.6         WCAG 2.2 conformance requirements
    Type of assessment      Inspection
    Requirement             1. The ICT is, or includes, a web page.
    Preconditions
    Procedure               1. Check that the web page satisfies WCAG 2.2 [4] conformance requirement "1:
                            Conformance level" at Level AA.
                            2. Check that the web page satisfies WCAG 2.2 [4] conformance requirement "2:
                            Full pages".
                            3. Check that the web page satisfies WCAG 2.2 [4] conformance requirement "3:
                            Complete processes".
                            4. Check that the web page satisfies WCAG 2.2 [4] conformance requirement "4:
                            Only Accessibility-Supported Ways of Using Technologies".
                            5. Check that the web page satisfies WCAG 2.2 [4] conformance requirement "5:
                            Non-interference".
    Result                  Pass: All checks are true
                            Fail: Any check is false
                            Not applicable: If any requirement precondition is false. (Do not need to meet or test)
```

### C.9.7 — User preferences for web pages

```
C.9.7         User preferences for web pages
    Type of assessment                                            Inspection
    Requirement             1. The ICT is, or includes, a web page.
    Preconditions
    Procedure               1. Check that the web page does not block the user agents mode(s) of operation that
                            present the web page according to user preference settings.
                            2. Check that the web page does not explicitly override user preferences for
                            documented platform accessibility features in these modes of operation.
                            3. Check each case where a user preference is explicitly overridden to identify whether
                            meeting the user preference would fundamentally alter the information or function of
                            the web page.
    Result                  Pass: All checks are true
                            Fail: Check 1 is false OR Check 2 is false OR Check 3 is false
                            Not applicable: If any requirement precondition is false. (Do not need to meet or test)
```
