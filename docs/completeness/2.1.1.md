# Completeness derivation — SC 2.1.1 Keyboard, clearing direction

**Resolver:** `all-true-completeness-v1` · **Clearability:** `closed-scope-clearable` (single-mode only) ·
**accessibilitySupportDependent:** `false` · **Experiment:** `keyboard-activation`.

SC 2.1.1 (A): *all* functionality is operable through a keyboard. "All functionality" is a universal
over an element's behaviours — **open** for a composite widget (a slider also has Home/End/PageUp; a
grid has typeahead + Ctrl combos). The universal collapses to a finite, decidable contract **only**
for a single-mode control whose entire operable surface is {focus, activate}.

| Obligation (typed-outcome flag) | Why necessary |
|---|---|
| `hydrationReady` | key handlers are JS-attached; an under-hydrated control can falsely look inoperable. |
| `keyboardReachableInState` / `reachedForActivation` | the control must be reached by real keyboard before activation is tested (Rule 14). |
| `contractKeysAllOperated` | every key in the control's contract (button: Enter+Space; link: Enter; checkbox/radio/switch: Space) produced a real OBSERVED effect (AX delta / pixel / focus move / navigation). |
| `observableEffectStable` | the effect reproduced — not a one-frame `:active` flicker. |
| `realKeyDistinctFromSynthetic` | a synthetic-event probe must NOT already produce the effect; a handler keyed on synthetic events (or `isTrusted`) would otherwise false-clear. |
| `singleModeControl` | **universe-closing obligation.** Only a button/link/checkbox/… (not a composite/slider) has the finite {focus, activate} surface; composites fail this and auto-PARTIAL. |
| `modeInventoryClosed` | no `aria-haspopup`/`aria-controls`-to-composite/drag affordance that would reopen the behaviour set. |

A div-`role=button` with no key handler, or a synthetic-only handler, produces no real-key effect ⇒
`BARRIER_OBSERVED`. A genuine slider with arrow support is correct but still cannot clear (its
behaviour set is open) ⇒ INCONCLUSIVE — the deliberate conservative 2.1.1 discipline.

## Body-mutation expectation
Dropping any obligation ⇒ PARTIAL. Published claim is observation-scoped, `conformanceOutcome: NOT_ASSESSED`.
