# Completeness derivation — SC 1.4.3 Contrast (Minimum), clearing direction

**Resolver:** `all-true-completeness-v1` · **Clearability:** `closed-scope-clearable` ·
**accessibilitySupportDependent:** `false` (contrast is perceived visually, without AT mediation) ·
**Experiment:** `text-contrast-pixel`.

SC 1.4.3 (AA): text/images-of-text have a contrast ratio of at least 4.5:1 (3:1 for large text).
A clear is sound **only** where the ratio is a finite decidable number — opaque flat foreground over
a single opaque flat backdrop. Any non-uniform backdrop (image/gradient), alpha compositing the
runner cannot resolve, or a colour that varies between frames makes the universal ("every glyph
pixel meets the ratio") undecidable, so the clear is withheld (INCONCLUSIVE → PARTIAL).

| Obligation (typed-outcome flag) | Why necessary (failure mode if dropped) |
|---|---|
| `textRendersVisible` | invisible/zero-area/SR-only text is not in scope; a "clear" on it is vacuous. |
| `foregroundResolved` | the effective glyph colour must be resolved (incl. `rgba` alpha + ancestor `opacity`), not the nominal `color`, else a translucent fg false-clears. |
| `backgroundResolved` | an opaque backdrop must be found; assuming white when it is unresolved false-clears (or false-barriers). |
| `backdropIsSolidUniform` | **universe-closing obligation.** Over an image/gradient the ratio is per-pixel; a single sample cannot prove every glyph pixel clears. Non-uniform ⇒ never clear. |
| `contrastComputable` | a single deterministic ratio must exist (fg+bg opaque & uniform). |
| `sizeClassResolved` | the 4.5 vs 3.0 threshold must be chosen from measured px+weight (`isLargeText`), not guessed. |
| `thresholdMet` | the measured ratio must actually meet the chosen threshold. |
| `notExemptText` | disabled/decorative/`aria-hidden` text is exempt; not a clear and not a barrier. |
| `measurementStable` | two reads a few frames apart must agree — a colour-cycling animation must not clear on a lucky frame. |

## Body-mutation expectation
Dropping any one obligation must turn the clear into PARTIAL. The build's drop-any test enforces the
set as a whole. The published claim is observation-scoped and carries `conformanceOutcome: NOT_ASSESSED`.
