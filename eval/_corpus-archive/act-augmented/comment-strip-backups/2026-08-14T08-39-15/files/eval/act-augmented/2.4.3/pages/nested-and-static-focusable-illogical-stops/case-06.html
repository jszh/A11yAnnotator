Sending requests

Every Cortex API call is an HTTPS request authenticated with your secret key.

Make your first request

Send a POST to the messages endpoint with a JSON body:

POST https://api.cortex.dev/v1/messages
Authorization: Bearer sk_live_…
Content-Type: application/json

{ "model": "cortex-1", "input": "Hello" }

Required headers

All requests must include an Authorization header and a JSON content type.
