Why automated tools miss this: the region is a valid role="status" live region and aria-atomic="false" is well-formed, valid ARIA — axe, WAVE, and Lighthouse see correct markup and raise nothing. The defect is that aria-atomic="false" was set on purpose, so when only the inner number node is rewritten the screen reader announces the bare token (e.g. "two") with no "refills remaining" framing. No rule exists for "the announced fragment is semantically incomplete"; judging whether the spoken word alone conveys the same meaning as the visible whole requires a human (or AT) to fire the update and listen.
