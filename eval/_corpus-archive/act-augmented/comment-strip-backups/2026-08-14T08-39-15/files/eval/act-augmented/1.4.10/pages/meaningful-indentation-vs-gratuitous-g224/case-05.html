Connect your database

Run these commands from a machine that can reach your database, then paste the seed row so we can confirm the connection. You can copy each block with the Copy button.

1. Pull and start the connector

This single command downloads the connector and registers it with your workspace token.

bash
# run from any host with outbound HTTPS
curl -fsSL https://downloads.quanta-analytics.example.com/connector/install.sh | sh -s -- --workspace=acme-prod --token=qa_live_8f3c2b91d04e47aa9c6 --region=us-east-1 --telemetry=off

2. Insert the verification row

Run this SQL against the database you want to connect. It writes one row our connector reads back to confirm read/write access.

sql
INSERT INTO quanta_handshake (workspace, region, issued_at, nonce, note) VALUES ('acme-prod', 'us-east-1', now(), 'b7Q19zKpL2', 'created by quick-start step 2; safe to delete after verification');

Once both commands succeed, return here and we will detect the handshake automatically.
