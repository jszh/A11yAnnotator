Writing an idempotent backfill task

A backfill recomputes historical partitions. To be safe to re-run, it must skip partitions that already landed and only emit rows for the window it owns. The block structure below is what makes that decision tree readable.

The decision tree

The nesting in run_backfill mirrors the logic exactly: each deeper indent is a condition that must hold before the inner statements run. Removing or wrapping the indentation would make it impossible to see which else pairs with which if.

Note the continue on the verified-skip branch versus the partition.commit() at the bottom of the loop body. Their relationship is visible only because of the indentation level each sits at.

Why this stays preformatted

This is the one place on the page where text deliberately does not wrap. In Python, indentation is not decoration — it determines which block a statement belongs to, and the language will refuse to run if it is altered. So at a narrow viewport this code is allowed to scroll horizontally as an excepted section of content; we only shrink the tab width to keep that scrolling to a minimum.
