Accessibility note (why automated tools miss this). Tabbing through the six links above does change pixels — the user-agent paints its dotted keyboard-focus ring on the focused link. An ACT-style focused-vs-unfocused pixel diff on that single element is therefore non-zero, and axe-core / WAVE / Lighthouse report no error (the focus indicator is never set to outline:none). But the author already gave every link a permanent outline:1px dotted #000 — the identical style, weight and colour as the UA ring. A sighted keyboard user cannot tell which link is focused because all six look the same dotted box at rest. Catching this requires a human to compare the focused link against the resting appearance of its neighbours and judge that the change is not distinguishing — exactly the F78 mode-2 failure.
