هيئة النقل العام — خدمة المواطنين

ملاحظة حول إمكانية الوصول. كتب المطوّر نمطًا للتركيز فعلاً، لكنه اختار حلقةً بسمك بكسلين وبلون أسود (‎#1a1a1a‎) يطابق لون الإطار الدائم بسمك ٣ بكسل، وبدون إزاحة، فتُرسم الحلقة ملاصقةً للإطار السميك بنفس اللون فيبتلعها، ولا يستطيع مستخدم لوحة المفاتيح تمييز الحقل الذي يحمل التركيز. Why automated tools miss this. Focus is NOT disabled: an author :focus-visible rule paints a real outline:2px solid #1a1a1a, so no control uses outline:none and a focused/unfocused pixel diff is non-zero — axe-core, WAVE and Lighthouse pass 2.4.7. But the author chose the ring in the SAME near-black as the permanent border:3px solid #1a1a1a and set outline-offset:0, so the thinner ring is drawn flush against the thicker same-colour frame and is occluded by it; a keyboard user cannot tell which control is focused. Concluding that a same-colour ring against a thicker same-colour border fails the "visible" definition requires a human comparing the focused edge to its adjacent border colour (F78 mode 3). The colour is author-set, so the failure does not depend on the browser's default ring; the RTL/Arabic context does not change the verdict.
