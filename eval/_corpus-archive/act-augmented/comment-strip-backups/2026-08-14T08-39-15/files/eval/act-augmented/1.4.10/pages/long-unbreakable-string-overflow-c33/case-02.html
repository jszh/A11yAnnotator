Authenticating requests

Every call to the Meridian Payments API is authenticated with a secret bearer token. Treat it like a password: never commit it to source control and never expose it in client-side code.

Sending the token

Pass your secret in the Authorization header on every request, prefixed with the word Bearer and a single space. The block below shows a complete example using cURL — this fenced block scrolls on its own and reflows fine:

curl https://api.meridianpay.example/v1/charges \
  -H "Authorization: Bearer mp_live_..." \
  -d amount=2000 -d currency=gbp

Your test token

For this sandbox session the exact secret you should send is mp_test_8Kd2Lf9Qe4Rt7Yu1Io5Pa3Sg6Hj0Kl2Zx8Cv4Bn7Mq1Wr5Et9Yu3Io6 — copy it verbatim, including the mp_test_ prefix, into your environment variable. The value is shown inline so you can select the whole secret in one drag without accidentally grabbing surrounding punctuation.

Heads up: rotating a token immediately revokes the previous one. Update every running service before you rotate, or in-flight requests will start returning 401 Unauthorized.
