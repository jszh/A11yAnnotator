Glyphwright SDK v3.2.0 REST API Reference

Typeface Rendering API

Programmatic access to font shaping, glyph rasterization, and subsetting for the Glyphwright cloud renderer.

Overview

All requests are authenticated with a bearer token and must target the regional host that matches your project. Responses are JSON unless a binary glyph atlas is requested with Accept: image/png.

Authentication

Pass your key in the Authorization header. Keys are scoped per project and can be rotated from the dashboard.

curl https://eu.glyphwright.dev/v3/fonts \
  -H "Authorization: Bearer gw_live_8f2c..."

List fonts

GET/v3/fonts

Returns the fonts available to the calling project, including foundry metadata and licensed weights.

Shape a string

POST/v3/shape

Runs the HarfBuzz-compatible shaping pipeline and returns positioned glyph IDs.

FieldTypeDescription
textstringUTF-8 source to shape.
featuresarrayOpenType feature tags, e.g. ["liga","kern"].
directionstringltr, rtl, or auto.

Subset a font

POST/v3/subset

Produces a reduced font file containing only the requested code points.

Pagination

Collection endpoints return cursor-based pages. Follow the next cursor until it is null.

Errors

Errors use standard HTTP status codes with a machine-readable code and a human message.

Rate limits

The shaping endpoint is limited to 600 requests per minute per project on the Pro plan.
