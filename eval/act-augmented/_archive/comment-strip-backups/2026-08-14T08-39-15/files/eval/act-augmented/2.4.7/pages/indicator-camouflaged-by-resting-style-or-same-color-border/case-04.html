Why automated tools miss this. There is a real, author-supplied focus style (button:focus { box-shadow: 0 0 0 1px #1b2a4a }), so no scanner can flag a "removed" indicator, and a focused/unfocused style diff is non-zero. axe-core, WAVE and Lighthouse pass 2.4.7. Yet each button already wears a permanent 8px solid #1b2a4a border, and the thin custom ring spreads in the exact same navy flush against that border's outer edge with no gap — so 1px of navy added to an 8px navy frame merges in and the focused chip reads as the same navy box it did at rest. A keyboard user cannot tell which of the five toolbar buttons is focused. Recognising that a thin same-hue ring laid flush against a thicker same-hue border is not distinguishing requires human visual judgment about perceptual contrast, not the computed-style change an automated rule detects (F78 mode 3).
