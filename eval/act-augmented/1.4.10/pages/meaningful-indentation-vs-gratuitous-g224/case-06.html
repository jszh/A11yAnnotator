Send a test event

Use these examples to deliver a test event to one of your webhook endpoints. The lines are long, so each code block has a Wrap lines toggle — turn it on to read the whole command in a single column without scrolling sideways.

Trigger from the CLI container

This runs the Relay CLI in Docker and posts a sample invoice.paid event.

bash 
# long, but a shell command wraps without losing meaning
docker run --rm -e RELAY_API_KEY=$RELAY_API_KEY relayhq/cli:2.7 events send --endpoint=ep_9fa31c --type=invoice.paid --payload='{"id":"in_88421","amount":4200,"currency":"usd","customer":"cus_5512"}' --idempotency-key=test-2026-06-20-01

The JSON body that gets delivered

Your endpoint receives a single JSON object. Wrapping it changes nothing about its meaning.

json 
{"id":"evt_3a91f0c2","type":"invoice.paid","created":1750000000,"data":{"invoice":"in_88421","amount":4200,"currency":"usd","hosted_url":"https://pay.relay.example.com/i/in_88421?sig=Zk19"}}
