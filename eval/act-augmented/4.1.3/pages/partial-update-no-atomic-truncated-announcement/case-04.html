Why automated tools miss this: the count line is a valid role="status" region with correct contrast, a labelled search field, and real catalogue results — axe/WAVE/Lighthouse pass it. The defect is that only the inner numeral node updates while the region is non-atomic, so AT speaks a bare "٢٤" without the "النتائج … نتيجة" (results) framing. No automated rule judges whether an orphaned numeral — especially one stripped of both its RTL-leading label and trailing unit — conveys the same meaning as the visible whole.
