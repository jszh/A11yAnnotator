Why automated tools cannot catch this (EN): Pressing “تجديد” (Renew) clones a <template> whose markup ALREADY contains <div role="status" aria-live="polite">…</div> with the confirmation text baked in, then appends that clone. Inspect the result: a valid Arabic role="status" live region with a real confirmation message — axe/WAVE/Lighthouse pass it. But the region clone arrives already holding its content; no empty live region was ever registered at load, so most screen readers announce nothing. A snapshot cannot tell that the cloned subtree carried the role attribute and the text together.
