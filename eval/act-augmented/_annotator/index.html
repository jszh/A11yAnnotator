Annotator settings & info

Optional page-filter JSON

Load a JSON file (⛶ Filter) to restrict which pages appear. Any of these shapes work:

// a) array of selectors (string or object)
["1.1.1", "1.4.3/contrast-from-gradient", "2.4.4/link-purpose/case-02"]

// b) array of objects
[{"sc":"1.1.1"}, {"sc":"2.4.4","aspect":"link-purpose"},
 {"sc":"2.4.4","aspect":"link-purpose","caseId":"case-02"}]

// c) wrapped
{"include": ["1.1.1", {"sc":"4.1.2"}]}

// d) seeded order + work-split slice (deterministic)
{"include": ["1.1.1","1.4.1"], "seed": 42, "slice": {"ranges": [[0, 0.5]]}}

A selector with only an SC includes every page of that SC; SC+aspect includes the whole aspect; SC+aspect+caseId includes one page. Default (no file) = all pages. seed shuffles SC/aspect/case order deterministically; slice.ranges keeps fractional ranges of that order (for splitting work across annotators — see splits/).

Annotations + the inspection log autosave to this browser's localStorage; Export downloads everything as JSON.
