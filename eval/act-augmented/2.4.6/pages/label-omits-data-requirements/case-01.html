Demo note (not shown to users): This page fails WCAG 2.4.6 Test 5.B. The visual label "Date" names the topic correctly but states none of the field's data requirements. The input is a free-text field (not type=date, so no native picker reveals the format) whose JavaScript validator below accepts only DD-MM-YYYY. Automated checkers pass it: the <label> is present, correctly associated via for, and non-empty, so axe-core/WAVE/Lighthouse report a properly labelled field.
