Recover from a stuck reflow worker

Run these steps in order. Each step assumes the previous one finished — skipping ahead can corrupt the job queue.

  1. Drain the active queue

    Pause intake so no new reflow jobs are accepted while you work.

  2. Kill the wedged worker

    Terminate the PID holding the lock; confirm the lock file is released before continuing.

  3. Replay the dead-letter batch

    Re-enqueue only the jobs that failed after the worker stalled, oldest first.

  4. Resume intake

    Un-pause the queue and watch the dashboard for one full cycle before closing the incident.

Order is mandatory: resuming intake (step 4) before the dead-letter batch is replayed (step 3) duplicates jobs.
