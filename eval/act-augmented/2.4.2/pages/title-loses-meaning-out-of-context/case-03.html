Helios Identity API v3 › Users › List users

GET /v3/users

Returns a paginated list of every user provisioned in your Helios Identity directory. Requires the directory:read scope on the access token.

Query parameters

NameTypeDescription
limitintegerItems per page (1–200, default 50).
cursorstringOpaque pagination cursor from the previous response.
statusenumactive, invited, or deactivated.

Example request

curl https://api.helios.io/v3/users?limit=2 \
  -H "Authorization: Bearer $HELIOS_TOKEN"

Example response 200 OK
