Release notes — Quartzdb v4.2.0 latest

Released 11 June 2026 · quartzdb@4.2.0

Upgrade

Upgrading from 4.1.0 to 4.2.0 is a drop-in replacement; no schema migration is required. Pin the new version:

npm install quartzdb@4.2.0

What's new in 4.2.0

  • Vectorized aggregation engine — GROUP BY over wide tables is up to 3.1× faster than 4.1.0.
  • New WINDOW clause for running totals, introduced in 4.2.0.
  • TLS 1.3 by default for the wire protocol (was opt-in in 4.1.0).

Bug fixes in 4.2.0

  • Fixed a planner regression present since 4.1.0 where correlated subqueries could deadlock.
  • Fixed UTF-8 handling in IMPORT CSV reported against 4.1.0.
