POST /v1/payment_intents

Creates a PaymentIntent object. A PaymentIntent tracks the lifecycle of a customer checkout flow and the resulting charges. After creating a PaymentIntent, attach a payment method and confirm it to continue the payment.

curl https://api.acme.com/v1/payment_intents \
  -u "sk_test_4eC39H...:" \
  -d amount=2000 \
  -d currency=usd \
  -d "automatic_payment_methods[enabled]"=true
amount integer · required

Amount intended to be collected, in the smallest currency unit (e.g. 2000 = $20.00).

currency string · required

Three-letter ISO currency code, in lowercase.

customer string · optional

ID of the Customer this PaymentIntent belongs to.
