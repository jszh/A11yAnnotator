Webhooks

Receive real-time notifications when events happen in your Vaultpay account.

On this page: Register an endpoint Payload shape FAQ

Register an endpoint

Send a POST to /v1/webhook_endpoints with the URL you want to receive events on. Vaultpay signs every delivery with your endpoint secret.

curl https://api.vaultpay.com/v1/webhook_endpoints \
  -u sk_test_4242: \
  -d url="https://example.com/hooks" \
  -d "enabled_events[]=charge.succeeded"

Payload shape

Each delivery is a JSON object with a top-level type and a data.object matching the resource for that event.
